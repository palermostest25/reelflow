# Reelflow interface
World: an independent radio station's playout desk. Warm pale canvas, black ink, rust-red transport controls, condensed editorial headings, fine ruled schedules. Operator mode: the queue leads; footage and controls remain visible, and failures have plain recovery paths.

Grounded candidates: radio playout desk, DJ record sleeve index, venue running sheet, broadcast continuity log (assigned fourth), photo contact sheet, studio patch-bay, flight departure board. The chosen broadcast continuity log places time, destination, clip, and state on shared rules. The vertical-video challenger informs a large playable inspector but loses multi-post scanability; zoo map, acetate manual, dance notation and barcode field obscure operational states. The console challenger is competitive on scanability; borrow its separation of destructive controls without its technical visual language. No new imagery is required: actual footage supplies it.

Typography: locally served Barlow Condensed for headings and DM Sans for body, with font licenses retained. Tight headings, readable 15px body, tabular times. Rust #a43421 primary; pale #f4f1e9 surface; ink #202720; muted #63685e; green #315c43 for ready. Small uppercase only for table column labels, never a kicker above headings.

Composition: persistent narrow navigation; horizontal run controls; large queue and a quiet right-hand operational summary. Rows instead of metric cards. Media library becomes a true contact sheet. Caption editing lives in a focus-protected drawer with video preview. Mobile navigation becomes a compact horizontal bar and queue rows stack.

States: no invented footage or performance results. Empty queue gives a useful account/AI/footage setup path. Dry run and paused always visible. Keyboard focus is rust; reduced motion supported. Mutations surface progress/errors in a live status region.
